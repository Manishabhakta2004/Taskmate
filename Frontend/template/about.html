About TaskMate

TaskMate is a modern full-stack task management application designed to help users efficiently organize their daily tasks. It is built with a Flask (Python) backend and a clean frontend using HTML, CSS, and JavaScript.

Key Features

  • Add, update, and delete tasks: Quickly manage your to-dos with a simple interface.
  • Mark tasks as completed: Track your progress easily.
  • Filter tasks: View All, Pending, or Completed tasks with one click.
  • REST API backend: Clean architecture for scalability and integration.
